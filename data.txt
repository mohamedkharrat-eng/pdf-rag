## Project 1: Chest X-Ray Pneumonia Detector
Built and deployed a Chest X-Ray Pneumonia Detector on Hugging Face Spaces. Uses ResNet50 with Transfer Learning and a Gradio interface. Achieved 86.7% accuracy. During development, Mohamed resolved challenges including class imbalance, overfitting, and fine-tuning instability.

## Project 2: Shoplifting Detection System
A shoplifting detection system currently in progress. Uses YOLOv8 for object detection combined with ByteTrack for object tracking, aimed at identifying suspicious behavior in retail video footage.

## Project 3: Agency Management Web App
Built during a web development internship at We Are Digital Tech Services in Tunis. A Laravel 11 + MySQL digital marketing agency management application. Covers client, service, publication, employee, and task modules. Features dual-authentication with separate admin and employee guards, a FullCalendar scheduler, and Chart.js statistics dashboards. Integrates RapidAPI for Instagram/Facebook data scraping. Repository hosted under wearetechdigitalservices-sketch on GitHub. Technical challenges solved included migration ordering conflicts and guard middleware conflicts. Applied Laravel concepts: MVC, Blade templating, Eloquent CRUD, Migrations, Middleware, session-based authentication, file upload handling, and custom guards.

## Project 4: Anber Patisserie E-commerce Site
A Laravel e-commerce website built for a family patisserie (pastry) business. Includes a home page, an admin panel, and product CRUD functionality with photo upload support. Shopping cart implemented via sessions, with email notifications sent through Gmail SMTP. Deployed on Railway. Technical challenges solved included InnoDB tablespace corruption and view file mix-ups.

## Project 5: PDF RAG Chatbot
A Retrieval-Augmented Generation (RAG) system built to chat with personal course PDFs and documents. Uses sentence-transformers for embeddings, FAISS for vector search, and Groq's API for answer generation, with a Streamlit chat interface deployed publicly.
